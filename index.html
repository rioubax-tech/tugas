Materi: Pengenalan cPanel

Dipresentasikan oleh Kelompok 2 · Sixora Group

1. Apa itu cPanel?

cPanel adalah control panel hosting berbasis web dengan tampilan grafis. Lewat cPanel, kita bisa mengelola hosting dan website langsung dari browser, tanpa harus mengetik perintah di terminal server. cPanel umumnya berjalan di server Linux dan banyak dipakai oleh penyedia layanan hosting.

2. Fitur Utama cPanel

File Manager Upload, edit, dan atur file website dari browser. Folder utamanya public_html.
Domains Menambah subdomain, addon domain, dan pengalihan (redirect).
Email Accounts Membuat email dengan domain sendiri, misalnya nama@domain.com.
Databases Membuat database MySQL dan mengelolanya lewat phpMyAdmin.
SSL/TLS Mengaktifkan HTTPS agar koneksi website lebih aman.
Backup Mencadangkan dan memulihkan file serta database website.
Metrics Melihat statistik pengunjung, pemakaian disk, dan bandwidth.
Installer Aplikasi Memasang aplikasi seperti WordPress dengan cepat (tergantung penyedia hosting).

3. Cara Login ke cPanel

  1. Buka alamat namadomain.com/cpanel atau namadomain.com:2083 di browser.
  2. Masukkan username dan password dari penyedia hosting.
  3. Klik Log in untuk masuk ke dashboard cPanel.

4. Upload Website lewat File Manager

  1. Login ke cPanel, lalu buka File Manager.
  2. Masuk ke folder public_html.
  3. Klik Upload, pilih file index.html beserta file pendukungnya.
  4. Buka nama domain di browser untuk memastikan website tampil.
  5. (Opsional) Aktifkan SSL agar website memakai HTTPS.

5. Kelebihan cPanel

  • Mudah dipakai karena tampilannya grafis dan terorganisir.
  • Fitur lengkap: file, domain, email, database, keamanan, dan backup dalam satu tempat.
  • Sangat umum dipakai, sehingga banyak panduan dan dokumentasi yang tersedia.
